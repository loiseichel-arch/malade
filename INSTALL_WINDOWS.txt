INSTALLER MALADE SUR WINDOWS
=============================

1. Dézippe le fichier téléchargé, puis dézippe Malade.vst3.zip.

2. Copie le dossier Malade.vst3 dans :
      C:\Program Files\Common Files\VST3\
   (Windows demande une confirmation administrateur : accepte.)

3. Relance ton logiciel audio et fais un nouveau scan des plugins.
   Malade apparaît sous le constructeur « Planet Gloria ».

App autonome : Malade.exe se lance directement. Le programme n'est pas
signé : si Windows affiche « Windows a protégé votre ordinateur », clique
sur « Informations complémentaires » puis « Exécuter quand même ».

AAX (Pro Tools) : Malade.aaxplugin n'est pas signé PACE. Il ne se charge
que dans Pro Tools Developer, à copier dans :
   C:\Program Files\Common Files\Avid\Audio\Plug-Ins\
Dans un Pro Tools normal, charge le VST3 via Blue Cat PatchWork.
